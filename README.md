# Paju, slowly

2026년 8월 15일-17일 파주 2박 3일 여행을 위한 인터랙티브 스토리맵입니다.

## 주요 기능

- 1일차부터 3일차까지 날짜별 이동 경로 지도
- 장소 선택에 맞춘 지도 포커스와 시간대 배경 변화
- 차량 마커가 경로를 따라 움직이는 일정 재생
- 장소별 공개 사진, 후기 요약, 원문과 지도 링크
- 폭염과 비에 대응하는 대체 일정
- 시스템 색상 모드와 수동 테마 전환
- 모바일 반응형 및 모션 감소 설정 지원

## 로컬 실행

별도 빌드 과정이 없는 정적 페이지입니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.
